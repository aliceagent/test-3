# Voice Agent Script (NewVoices)

Context: NewVoices builds custom enterprise voice agents. Demos are client-specific
adaptations of proven base scripts (Alpen "Emily" outbound scripts → Heineken,
MultiView, Grab pitches). Pricing anchor: ~$18K/month per use case.

## Process
1. Start from the closest existing sample script — preserve its call architecture, don't invent a new one.
2. Rewrite for the client's brand, audience, and single clear objective (survey completion, demo booking, churn save, lead qualification).
3. Keep it *speakable*: short sentences, contractions, no bullet-list diction. Read it aloud mentally — anything that sounds like text, rewrite.

## Script skeleton
- **Opening**: agent name, company, one-line reason for the call, permission check ("do you have a quick minute?").
- **Core flow**: 3–6 questions/steps max toward the objective; one idea per turn.
- **Objection handling**: scripted responses for "not interested", "how did you get my number", "is this AI?" (answer honestly and confidently), "call me later" (schedule it).
- **Edge cases**: voicemail message, wrong person, language switch (agents can switch languages mid-call — a selling point).
- **Close**: confirm the outcome, next step, warm goodbye.

## Demo-specific rules
- The demo must showcase: natural interruption handling, edge-case recovery, and multilingual ability — build at least one moment for each.
- For market-research demos (e.g. Heineken): questions must produce analyzable, structured answers (scale ratings, categorical choices), since transcripts feed dashboards downstream.
- Deliver as: script document + a one-paragraph "what to notice in this demo" note for the prospect.
