# Chinese Learning Content

Jonathan studies toward HSK 3. Default level: HSK 3 vocabulary (HSK 1–2 assumed known) unless stated otherwise.

## Parallel-text format (the one he keeps re-specifying)
Unless told otherwise, format each sentence block as:
```
English translation
中文句子
中文句子      ← repeated a second time
English translation
```
- No timestamps. No pinyin/transliteration unless explicitly requested.
- Plain text files, one blank line between sentence blocks (they get read aloud / used for shadowing).

## Vocab lists
- Table columns: 中文 | Pinyin | English. Group by theme (kitchen, travel, etc.).
- When building from a source (video, lesson range), be exhaustive — he checks completeness.

## "十种…" (Ten Types of…) YouTube series
- Each episode: one "ten types of X" concept for HSK 3 learners.
- Governing constraint: **every item must be a concrete, picturable noun** (it gets illustrated). Reject abstract items.
- Master plan exists: 100 topics, ~1,000 vocabulary words in thematic categories — extend it, don't duplicate topics.

## Quiz/test websites
- Multiple choice, mobile-first (tap targets), immediate right/wrong feedback per question, running score, final accuracy summary. Batch questions ~5 at a time.

## Stories for class
- Use only the specified vocab list + HSK 1–3 words; write each sentence with the target words bolded; keep sentences readable aloud in class.
